# AnyEnchant (เฟส 2)

Paper plugin: ใส่ Enchant อะไรก็ได้กับไอเทมอะไรก็ได้ เลเวลสูงสุด 10 (ปรับได้ใน config)

## เฟส 1 มีอะไร
- `/ae enchant <เอนชานท์> <เลเวล> [ผู้เล่น]`  ใส่ Enchant ให้ไอเทมในมือหลัก (เลเวล 0 = ลบ)
- `/ae list`  ดูรายชื่อ Enchant ทั้งหมด,  `/ae reload`  รีโหลดตั้งค่า
- Anvil: รวม Enchant ข้ามชนิดไอเทมได้ ไม่มีข้อขัดแย้ง เลเวลเท่ากันรวมกัน +1 จนถึงเลเวลสูงสุด
- ภาษาไทย/อังกฤษ (`language:` ใน config.yml) สิทธิ์: `anyenchant.admin` (ค่าเริ่มต้น OP)

## เฟส 2: ความสามารถพิเศษ (เมื่อ Enchant อยู่บนไอเทมที่ไม่ใช่ของตัวเอง ไอเทมของตัวเองทำงานแบบ vanilla)
- **Blast Protection** บนอาวุธ/เครื่องมือ/ไอเทมอื่น: Shift + คลิกขวา = ระเบิดรอบตัว (ไม่ทำลายบล็อก ผู้ใช้ไม่เจ็บ)
- **Channeling** บนอาวุธ: ตีโดนมีโอกาสฟ้าผ่าเป้าหมาย (ไม่ต้องมีพายุ) / บนเครื่องมือ: Shift + คลิกขวา = ฟ้าผ่าจุดที่เล็ง / บนเกราะ: ถูกตีมีโอกาสฟ้าผ่าผู้โจมตี
- **Efficiency** บนอาวุธ: ถือในมือแล้วตีเร็วขึ้น (ลดคูลดาวน์การตี)
- ค่าทั้งหมดปรับได้ใน config.yml หัวข้อ `abilities`

ยังไม่มี (เฟสถัดไป): Enchanting Table/GUI, lore, ความสามารถของ Enchant ตัวอื่น

## วิธีได้ไฟล์ .jar

### วิธี A: GitHub Actions (ไม่ต้องติดตั้งอะไร)
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`)
2. เปิดแท็บ **Actions** รอ workflow "Build" ทำงานจนเสร็จ
3. เปิดรอบที่รันเสร็จ ดาวน์โหลด artifact ชื่อ **AnyEnchant** ข้างในคือ `AnyEnchant-0.1.0.jar`

### วิธี B: บิลด์เองในเครื่อง
ต้องมี JDK 25 และ Maven แล้วรัน `mvn package` ไฟล์จะอยู่ที่ `target/AnyEnchant-0.1.0.jar`

นำ .jar ไปไว้ในโฟลเดอร์ `plugins/` ของเซิร์ฟเวอร์ Paper แล้วรีสตาร์ต

ถ้าบิลด์ไม่ผ่าน ให้ส่งข้อความ error มาให้ฉัน ฉันจะแก้และส่งเวอร์ชันใหม่
